# Project: Job Market Analyzer

## About me
I'm learning to program while building this. My priorities, in order:
1. Understanding *why*, not just getting working code
2. A real, deployable app I'll actually use

## How to work with me
- Always explain your reasoning: why this approach, what alternatives existed, what tradeoffs were made
- Keep changes scoped — one focused task at a time, not sprawling multi-file changes unless I ask
- When introducing a new concept or tool, briefly explain what it is before using it
- Prefer clarity and simplicity over cleverness — I need to be able to read and understand the code
- After significant changes, suggest what to test/verify before moving on
